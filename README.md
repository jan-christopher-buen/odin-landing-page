# odin-landing-page

A landing page built with HTML and Flexbox for The Odin Project.

**Live preview:** https://jan-christopher-buen.github.io/odin-landing-page/

## About

This page recreates the layout of The Odin Project's landing page design, filled with my own content about learning web development from scratch.

## What I practiced

- Turning a design image into a full web page, one section at a time
- Page layout with Flexbox: `justify-content`, `align-items`, `gap`, and `flex-shrink`
- Keeping sections aligned with consistent padding
- Loading a web font (Roboto) from Google Fonts
- Styling links to look like buttons
- Committing each section separately with clear commit messages

## Built with

- HTML
- CSS (Flexbox)
